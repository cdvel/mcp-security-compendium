MCP security material is spread across spec pages, lab write-ups, papers and advisory databases, and some of it predates the 2026-07-28 spec. This list keeps the entries with a credible author and a primary source, organized by the component each one acts on. Every entry names its author and date.

<details>
<summary>Terms and threat tags</summary>

- **CIMD:** OAuth Client ID Metadata Document, a URL that identifies an OAuth client; preferred for client registration in the 2026-07-28 spec.
- **DCR:** OAuth Dynamic Client Registration (RFC 7591), deprecated in the 2026-07-28 spec.
- **PRM:** OAuth Protected Resource Metadata (RFC 9728), how an MCP server names its authorization server.
- **DNS rebinding:** a web page reaching a server on localhost by changing what its domain resolves to.
- **Tool poisoning:** instructions hidden in tool descriptions or output that an agent follows.
- **CoSAI threat tags:** `T1` authentication and identity, `T2` access control, `T3` input validation, `T4` instruction and data boundary (prompt injection), `T5` data protection, `T6` integrity and verification, `T7` session and transport, `T8` network binding and isolation, `T9` trust boundaries and privilege, `T10` resource limits, `T11` supply chain and lifecycle, `T12` logging and audit.
