# Changelog

Changes to sections, scope and inclusion rules. Individual entries added or removed are in the git history.

## Unreleased

- Seven sections by component: Specification and authorization, Clients and hosts, Servers, Gateways and proxies, Registries and supply chain, Threat models and research, Incidents. A planned *Detection and monitoring* section was merged into *Gateways and proxies* before release.
- Entries carry CoSAI threat tags `T1`–`T12`.
- Inclusion rules: 300 stars counts as a strong signal; advisories in general agent tools are tracked only when the root cause is in MCP handling; an unreachable primary source is kept only for very high reputation issuers or through an archived copy.
